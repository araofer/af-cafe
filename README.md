# ☕ AF Café

Um site institucional para uma cafeteria fictícia, desenvolvido como projeto de estudos em desenvolvimento web.

O AF Café apresenta uma experiência visual inspirada no universo das cafeterias, com identidade visual própria, cardápio organizado por categorias e informações sobre o estabelecimento.

## 📸 Sobre o projeto

O site conta com:

- Página inicial com banner em carrossel.
- Seção Sobre Nós.
- Cardápio dividido em quatro categorias:
  - Expresso
  - Cappuccino
  - Gelados
  - Especiais
- Cards de produtos com imagens, descrições e preços.
- Janela modal para informações de localização.
- Rodapé com informações institucionais e navegação.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.8
- JavaScript
- Visual Studio Code

## 🚀 Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/araofer/af-cafe.git
```

2. Entre na pasta:

```bash
cd af-cafe
```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar uma extensão como Live Server no Visual Studio Code.
